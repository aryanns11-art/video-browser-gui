# 🎥 Video Browser GUI

A modern desktop GUI application built using Python and CustomTkinter.

This project simulates a simple video browsing platform where users can search videos, explore categories, and view video listings through an intuitive graphical interface. It is designed as a beginner-friendly project for learning GUI development, image handling, and event-driven programming in Python.

---

## 🚀 Features

* 🔍 Video search functionality
* 🎬 Video listing cards
* 🏷️ Category filter buttons
* 👤 User profile section
* 🖼️ Custom image integration
* 🎨 Modern UI using CustomTkinter
* 🖥️ Desktop application interface

---

## 🛠️ Technologies Used

* Python 3
* CustomTkinter
* Pillow (PIL)
* Object-Oriented Programming (OOP)

## ▶️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/video-browser-gui.git
```

### Navigate to the Project Folder

```bash
cd video-browser-gui
```

### Install Dependencies

```bash
pip install customtkinter pillow
```

### Run the Application

```bash
python main.py
```
